# De WeetWinkel

De WeetWinkel is CMN's knowledge base. It describes how CMN works: brand guidelines, coding
practices, how to give presentations and more. You reach it through the `weetwinkel` MCP server and
its `search`, `list_files` and `read_file` tools. Call `start_here` once for the full guide on how
to look things up.

## When to search

Search De WeetWinkel at the start of every task and whenever the task moves to a new topic, before
you write code, copy, designs or answers. For example:

- Asked to add an endpoint to a CMN service: search for the coding practices of that language and
  the name of the service.
- Asked to write a LinkedIn post: search for `tone of voice` and `social media`.
- Asked to prepare slides: search for `presentation` and `brand`.

Search even when you think you know the answer. CMN's conventions often differ from general best
practice, and De WeetWinkel is the source of truth for them. If a search finds nothing relevant,
continue without mentioning it.

## Using what you find

- Follow what De WeetWinkel says over your own defaults. When it conflicts with an explicit request
  from the user, follow the user and point out the conflict.
- Name the documents you relied on, so the user can check them.
